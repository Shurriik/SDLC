# Глоссарий проекта TrustRate

| Термин | Определение |
|---|---|
| TrustRate | Веб-приложение для формирования репутации пользователей на основе сделок, отзывов, верификации и истории поведения. |
| Актёр (Actor) | Внешняя по отношению к системе роль, взаимодействующая с TrustRate. |
| Администратор | Пользователь с полномочиями управления ролями и параметрами правил системы. |
| Антифрод | Набор правил выявления подозрительной активности и передачи событий на ручную проверку. |
| Апелляция | Обращение пользователя с просьбой пересмотреть решение модератора. |
| Баланс TC | Количество доступных пользователю единиц Trust Currency с учётом заблокированной части. |
| Верификация | Подтверждение email, телефона или документа пользователя. |
| Гость | Неавторизованный посетитель, который может просматривать публичные сведения и регистрироваться. |
| Залог доверия (Trust Escrow) | Временная блокировка TC на период сделки с последующим возвратом или списанием по установленным правилам. |
| Журнал операций TC | История начислений, списаний, блокировок и возвратов TC. |
| Сделка (Deal) | Запись о договорённости участников, проходящая через установленные статусы. |
| Модератор | Уполномоченный пользователь, рассматривающий жалобы, подозрительную активность и документы. |
| Отзыв (Review) | Оценка от 1 до 5 и необязательный комментарий после завершения сделки. |
| Поток событий (Flow of Events) | Пошаговое описание взаимодействия актёра и системы в прецеденте. |
| Прецедент (Use Case) | Описание цели актёра и последовательности взаимодействия с системой. |
| Репутация / рейтинг | Публичный показатель доверия пользователя, рассчитываемый по учитываемым отзывам и согласованным коэффициентам. |
| TC (Trust Currency) | Внутренние неденежные единицы доверия TrustRate; не являются деньгами и не выводятся. |
| UML | Unified Modeling Language — язык визуализации, спецификации и документирования систем. |
| PDF-отчёт о репутации | Документ с рейтингом, количеством отзывов, завершённых сделок и уровнем верификации пользователя. |
| Предусловие | Условие, которое должно быть выполнено до начала прецедента. |
| Постусловие | Состояние системы после завершения прецедента. |
| Основной поток | Нормальная последовательность шагов прецедента. |
| Альтернативный поток | Вариант выполнения при отклонении от основного сценария или ошибке. |
